1. Student Management System

2. Project Overview
A Python-based Student Management System that allows managing student records, including adding new students, viewing records, updating details, and deleting entries.
This project is designed for educational purposes and demonstrates modular programming.

4. File Structure
- `functions.py` : Contains all functions for managing students such as add, view, update, and delete.
- `Mainn.py` : The main program that runs the student management system and interacts with the user.
